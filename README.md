Імплеметнація до завдання:

Визначити абстрактний клас (або інтерфейс) «Електроприлад»
(назва, фірма, ціна). Визначити 3 похідні від нього класи:
«Порохотяг» (потужність,колір ), «Пральна машина»
(кількість програм, об’єм ), «Комбайн» (потужність,
кількість функцій). В текстовому файлі задано дані про 7
різних електроприладів. Зчитати дані в один масив і вивести
у Файл1 всі електроприлади, посортовані за назвою із
зазначенням їх кількості. Вивести у Файл2 список назв та
загальну вартість електроприладів вказаної фірми.
